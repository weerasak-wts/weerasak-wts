### Hi, I'm Weerasak 👋

**AI-assisted software engineer.** I build business systems with AI coding agents (mainly Claude Code).

**How I work — up front**

AI agents write most of the code. My job is the engineering around it:

- understand the real problem and the data before anything is built
- design the system and plan the work the agents do
- set the rules, tests and checks they must pass
- review what comes back, verify it on the running system, and own it in production

That is why the stack list below is wide: I ship working systems across these tools, but I don't claim to know each one by heart. When I don't know something, I check the docs, the logs and the data instead of guessing.

**What I build**

- **AI document pipelines** — classify and extract data from invoices, shipping documents, ID and business cards (LLM + OCR), then push it into the systems that use it
- **ERP integration** — SAP Business One (HANA, add-ons in C#) and NetSuite (SuiteScript)
- **Web apps and APIs** for internal teams
- **Tooling for AI agents** — running many Claude Code sessions together, agent skills, and a tool that turns a codebase into narrated explainer videos
